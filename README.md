# Kanji My Name ✦ 漢字

Turn any name into beautiful Japanese kanji calligraphy art — and choose the meaning behind every character.

**Live**: https://hitomiusausa.github.io/kanji-my-name/

- Phonetic *ateji* (当て字) conversion with curated, positive meanings
- Tap any kanji to pick a different meaning (love / dreams / strength / light…)
- 8 calligraphy fonts (3 free, 5 premium) — one font applied consistently to the whole name
- Vertical 縦 & horizontal 横 layouts, 3 free art styles + 2 premium, hanko seal
- Free full-size PNG download · Premium Pack $1: 4K, clean edition, all fonts & styles

Single static HTML file. No server, no build, no tracking.
